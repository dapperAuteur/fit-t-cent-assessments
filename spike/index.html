Slow-motion frame test

Checks whether a 120 or 240 fps clip reaches this page with every frame, and how fast this phone can decode it and find a pose in each frame.

Nothing leaves this phone. The clip is read inside this page and is never uploaded. No analytics, no cookies. The page keeps its results and a run counter in this browser only, so a crash or reload doesn't lose them.
